Set up Espframe

Connect a Guition JC8012P4A1 test frame by USB. Installing replaces the firmware on the frame.

Install firmware

To keep connections from ESPHome, leave Erase device unchecked during installation.

Connect Wi-Fi and Immich

Close the installer dialog after flashing, then fill in Wi-Fi and Immich below. If you already connected Wi-Fi in the dialog, choose Use Wi-Fi already saved on the frame.

# JC8012P4A1 V1 — Original panel

Use V1 when the ESP32-P4 chip is not v3.x and the rear-case marking is `2627` or lower. Chip information identifying v3.x takes precedence; use the [V3 guide](/screens/jc8012p4a1-v3) in that case.

## Install

In the [web installer](/install), select **V1 — Original panel** under **10-inch JC8012P4A1**, then flash over the display’s bottom USB-C port using a data cable. Follow the [installation steps](/install#steps) to configure WiFi and Immich.

V1 supports the USB web installer, the on-device OTA updater, and firmware upload from the device page. For recovery from a failed USB flash, see [USB flashing help](/usb-flashing).

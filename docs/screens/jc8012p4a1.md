# 10-inch Guition JC8012P4A1

All three profiles support the 10-inch 1280×800 landscape display. Select the firmware by the panel revision before installing.

## Identify your revision

Check chip information first. ESP32-P4 v3.x production silicon uses **V3**, regardless of the rear-case marking. Look in the ESPHome startup logs for the ESP32-P4 revision, or connect the display’s USB programming port and run `esptool --chip esp32p4 --port PORT chip_id` (replace `PORT` with the serial port for the display). The output identifies the chip revision. See Espressif’s [ESP32-P4 chip revision guide](https://docs.espressif.com/projects/esp-idf/en/release-v5.5/esp32p4/api-reference/system/chip_revision.html). If the chip information does not identify V3, use the four-digit rear-case marking as a fallback:

| Revision | How to identify it | Guide |
| --- | --- | --- |
| V3 — production silicon | ESP32-P4 v3.x | [V3 setup](/screens/jc8012p4a1-v3) |
| V2 — new panel | Case marking `2628` or higher, if chip is not V3 | [V2 setup](/screens/jc8012p4a1-v2) |
| V1 — original panel | Case marking `2627` or lower, if chip is not V3 | [V1 setup](/screens/jc8012p4a1-v1) |

## Install

Open the [Espframe installer](/install), choose **10-inch JC8012P4A1**, select V1, V2, or V3 explicitly, and follow the USB flashing prompts. The installer hides profiles whose release manifest is not yet published.

For initial WiFi and Immich setup, follow the [installation guide](/install#steps). If flashing fails, see [USB flashing help](/usb-flashing).

# JC8012P4A1 V2 — New panel

Use V2 when the ESP32-P4 chip is not v3.x and the rear-case marking is `2628` or higher. Chip information identifying v3.x takes precedence; use the [V3 guide](/screens/jc8012p4a1-v3) in that case.

## Install

In the [web installer](/install), select **V2 — New panel** under **10-inch JC8012P4A1**, then flash over the display’s bottom USB-C port using a data cable. Follow the [installation steps](/install#steps) to configure WiFi and Immich.

V2 uses panel startup settings for the newer panel revision. If the image is distorted, confirm the revision and install its matching firmware. For USB recovery, see [USB flashing help](/usb-flashing).

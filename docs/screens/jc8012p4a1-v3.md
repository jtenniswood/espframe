# JC8012P4A1 V3 — Production silicon

Use V3 when ESPHome startup logs or `esptool` reports ESP32-P4 v3.x production silicon. For `esptool`, connect the display’s USB programming port and run `esptool --chip esp32p4 --port PORT chip_id`, replacing `PORT` with the display’s serial port. Look for the reported ESP32-P4 revision. This takes precedence over the rear-case marking; do not identify V3 from the case marking alone. See Espressif’s [ESP32-P4 chip revision guide](https://docs.espressif.com/projects/esp-idf/en/release-v5.5/esp32p4/api-reference/system/chip_revision.html) and the [EspControl JC8012P4A1 V3 notes](https://jtenniswood.github.io/espcontrol/screens/jc8012p4a1-v3) for additional background.

## Install

In the [web installer](/install), select **V3 — Production silicon** under **10-inch JC8012P4A1** and flash via the bottom USB-C port with a data cable. Follow the [installation steps](/install#steps) to configure WiFi and Immich.

V3 keeps the same user-facing update paths as V1: USB web installer for first installation, the on-device OTA updater for future stable or beta firmware, and firmware upload from the device page. Each path selects the V3 firmware identity and artifacts. The initial USB installer and an OTA update still need physical V3 hardware validation; compile success alone does not confirm device behavior.

If USB flashing fails, see [USB flashing help](/usb-flashing).
